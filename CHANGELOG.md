# Журнал изменений

## [2.0.0] — 2026-10-16

Крупное обновление: переход на PyQt6, современный интерфейс с темами, хранение
данных в SQLite, обложки в WebP.

### Добавлено

- **Светлая и тёмная темы оформления** с оранжевым акцентом. Тема по умолчанию
  берётся из системных настроек, выбор сохраняется в базе данных.
- **Единое окно приложения**: страницы (полка, добавление книги, цитаты,
  настройки) переключаются внутри одного окна через `QStackedWidget`, без
  пересоздания окон.
- **Хранение данных в SQLite** (`data/library.db`): таблицы книг, цитат и
  настроек. Импорт и экспорт библиотеки в архив `.zip` (база + обложки) или в
  отдельный файл `.db`.
- **Обложки в формате WebP**: заметно компактнее JPEG/PNG. Поддержан выбор
  изображения в WebP, JPG, PNG и других форматах при добавлении книги.
- **Обратная совместимость**: старый `data/books-list.json` автоматически
  переносится в базу, архивы старого формата (с `books-list.json`) импортируются,
  обложки JPG/PNG из старых бэкапов конвертируются в WebP.
- **Автоматическая генерация обложек**: градиент, «корешок», рамка, заголовок с
  автоподбором размера шрифта и переносом строк, автор.
- **Меню сортировки**: одна кнопка с иконкой фильтра вместо трёх; в выпадающем
  списке видны варианты сортировки и текущий отмечен галочкой.
- **Контекстное меню книги (ПКМ)**: «Изменить книгу» и «Удалить книгу» прямо на
  домашней странице (удаление — с подтверждением).
- **Векторные иконки** (шестерёнка, солнце/луна, фильтр, экспорт/импорт),
  окрашиваемые под тему.
- **Анимации интерфейса**: плавное увеличение обложки книги при наведении.
- **Русская локализация диалогов** Qt (кнопки «ОК», «Отмена» и т. д.).
- **Плавный фон без полос** благодаря дизерингу градиента.
- **Сборка в один exe** (PyInstaller): статические ресурсы внутри, база и обложки
  создаются рядом с exe; пути адаптированы под работу из собранного приложения.

### Изменено

- Проект переведён с **PyQt5 на PyQt6** (обновлены импорты, enum'ы Qt,
  `exec_()` → `exec()`, диалоги `QFileDialog`, шрифты `QFont.Weight`).
- **Зависимости**: `PyQt6==6.11.0`, `pillow==12.3.0`, `setuptools==84.0.0`.
- **Страница настроек переделана**: две карточки «Экспорт» и «Импорт» с иконками
  и пояснениями вместо крупных кнопок.
- **Импорт и экспорт используют системный проводник Windows** (как при выборе
  обложки) вместо собственного диалога Qt.
- Тёмная тема стала нейтрально-серой (убран синий оттенок), тени обложек и
  карточек сделаны мягче.
- Расширена кнопка «Сохранить изменения», чтобы текст помещался.

### Удалено

- Три отдельные кнопки сортировки («А», «Н», «П»).
- Кнопки «Удалить книгу» и «Изменить» со страницы цитат (перенесены в ПКМ).
- Кнопка смены темы со страницы настроек (осталась только на главной).
- Подсветка обложки при наведении на главной странице.
- Формат хранения JSON (`data/books-list.json`, `data/settings.json`).
- Стрелка у кнопки «На главную» в настройках.

### Исправлено

- Контекстное меню книги открывалось в позиции последней книги, а не той, по
  которой кликнули.
- Текст на кнопке «Сохранить изменения» не вмещался.
- Видимые полосы на градиентном фоне окна.
- Незакоммиченные пользовательские данные попадали в репозиторий — обновлён
  `.gitignore`.
- В собранном exe папка `data/covers` не создавалась, и добавление книги без
  обложки приводило к вылету. Теперь каталоги создаются автоматически, а ошибки
  сохранения показываются диалогом вместо падения приложения.

### Документация

- README обновлён: актуальные инструкции по установке (виртуальное окружение
  `.env`), запуску, структуре проекта, хранению данных и темам.
