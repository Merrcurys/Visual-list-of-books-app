## О приложении
Book Tracker - это десктопное приложение, написанное на PyQt6, в котором вы можете вести трекинг прочитанных вами книг в графическом виде, а также добавлять цитаты. Это приложение будет полезно тем, кто ищет независимое приложение для отслеживания своих книг, не опасаясь стороннего вмешательства.

## Функционал домашней страницы
Добавленные книги отображаются на домашней странице. На домашней странице вы также сможете отсортировать отображаемые книги с помощью кнопки с иконкой фильтра в правом верхнем углу: по времени добавления, по названию или по автору (текущий вариант сортировки отмечен галочкой). Помимо этой кнопки есть кнопка для добавления новой книги и кнопки для перелистывания "полок" с книгами.

## Функционал страницы добавления книги
После нажатия кнопки "Добавить книгу", отобразится страница для добавления книги. Обязательными полями ввода являются поле автора и поле с названием книги. Если их не заполнить, высветится ошибка и попросит пользователя заполнить все поля. Обложка не обязательна: если её не добавлять, она сгенерируется автоматически — градиент с названием книги и автором. Свою обложку можно выбрать в форматах WebP, JPG, PNG и других — она сохранится в WebP.

## Функционал страницы добавления цитат
После нажатия на домашней странице по любой книге, отобразится страница для добавления цитат. В данном окне две кнопки для цитат: "Добавить цитату" и соотвественно "Удалить цитату". Изменить или удалить саму книгу можно по правому клику (ПКМ) по обложке книги на домашней странице: появятся пункты "Изменить книгу" и "Удалить книгу" (удаление запросит письменное подтверждение).

## Функционал страницы настроек
После нажатия на домашней странице на верхнюю левую кнопку настроек, отобразится страница с настройками. В данном окне две карточки: "Экспорт" и "Импорт". Экспорт сохраняет библиотеку в архив ZIP (база данных + обложки) или в отдельный файл базы данных SQLite, импорт загружает её обратно из `.zip` или `.db`.

## Хранение данных
Библиотека хранится в базе SQLite `data/library.db` — это единственный формат хранения приложения (JSON-файлы больше не используются). Обложки сохраняются в формате WebP (`data/covers/*.webp`) — он компактнее JPEG и PNG. Для обратной совместимости старые бэкапы и обложки в JPG/PNG автоматически конвертируются в WebP при импорте, а при первом запуске приложение переносит существовавший `data/books-list.json` в базу.

## Темы оформления
Приложение оформлено в современном стиле с оранжевым акцентом и поддерживает светлую и тёмную темы. По умолчанию тема берётся из настроек системы, переключить её можно кнопкой ☾/☀ на домашней странице. Выбранная тема сохраняется в базе данных.

## Установка

```bash
# 1) Создание виртуального окружения
python -m venv .env

# 2) Активация виртуального окружения
# Linux / macOS
source .env/bin/activate

# Windows (PowerShell)
.\.env\Scripts\Activate.ps1

# Windows (cmd)
.env\Scripts\activate.bat

# 3) Установка пакетов
pip install -r requirements.txt
```

## Запуск проекта

```bash
python main.py
```

## Структура проекта

```
main.py                       точка входа
core/                         логика данных
    storage.py                база SQLite, миграция и импорт/экспорт
    images.py                 работа с обложками (WebP)
interface/                    страницы и логика интерфейса
    main_window.py            единое окно и навигация между страницами
    shelf.py                  главная страница (полка книг)
    add_book.py               добавление и редактирование книги
    add_quote.py              страница цитат
    setting.py                страница настроек
template/                     описание интерфейса и оформления
    design.py                 темы (светлая/тёмная) и QSS-стили
    icons.py                  векторные иконки
    animations.py             анимации интерфейса
    *_interface.py            разметка страниц
data/                         данные приложения (library.db, обложки, шрифт, иконки)
```

## Прочее
Разметка страниц лежит в `template/*_interface.py` и поддерживается вручную.
Формат хранения обложек — WebP; старые JPG/PNG автоматически конвертируются при импорте.

```bash
# Команды для создания exe
pip install auto-py-to-exe

auto-py-to-exe
# Далее откроется удобный интерфейс для создания exe

# Если команда выше не сработала попробуйте эту
python3 -m auto_py_to_exe

#! После создания exe переместите в директорию всю папку data
```
